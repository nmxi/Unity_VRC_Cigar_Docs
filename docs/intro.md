# Mikinel Cigar Systemについて

このギミックは、VRChatワールド内で葉巻を楽しむ一連の流れを体験するギミックです。葉巻のカット、ライターによる着火、吸う、煙を吐く体験をPrefab配置のみで体験できます。

<ClickableImage src="/img/cigar-system-overview.png" alt="Mikinel Cigar Systemの概要" />

## できること

- フラットカット、パンチカットの2種類のカット
- ライターによる着火
- Useによる煙の吸入表現
- カット、着火、吸入などの効果音
- 灰を灰皿に落とす表現

## 基本の流れ

1. カッターで吸い口をカットする
2. ライターの火を葉巻の先端へ当てる
3. 葉巻を持ち、Useを押して吸う
4. 燃焼が進んだら、葉巻を軽く叩いて灰を落とす
